# Pet Bet

Telegram-бот на Go для виртуальных ставок на собственный следующий матч — в Dota 2 (ranked/competitive) и в CS2 (через FACEIT).

Проект работает только с виртуальными монетами. Здесь нет реальных денег, платежей, депозитов, вывода средств, KYC, bookmaker odds, betting API и ставок на pro-матчи.

Управление полностью кнопочное: `/start` открывает главное меню с выбором игры (🎮 Dota 2 / 🔫 CS2), привязка аккаунта — это не команда, а обычное сообщение с ID, суммы ставок выбираются кнопками (или вводятся текстом), и с любого экрана можно вернуться в меню кнопкой «🏠 В меню» вместо повторного `/start`. Кнопка «💳 Пополнить» зарезервирована под будущее пополнение баланса (сейчас — заглушка, монеты по-прежнему виртуальные).

## Механика MVP

1. Пользователь пишет `/start` — открывается главное меню.
2. Выбирает игру и привязывает аккаунт, просто отправив ID одним сообщением:
   - Dota 2: account_id, SteamID64 или ссылка на профиль Steam;
   - CS2: SteamID64, ссылка на профиль Steam или FACEIT-ник.
3. Бот сохраняет последний известный матч (`last_known_match_id` для Dota, `cs_last_known_match_id` для CS2).
4. Пользователь выбирает сумму ставки кнопкой (или вводит свою) и тип ставки — на победу в следующем матче.
5. Сумма списывается из доступного баланса и замораживается в `frozen_balance`.
6. Worker периодически проверяет историю матчей через Dota provider и FACEIT.
7. Первый новый матч после последнего известного считается целевым матчем ставки.
8. Если пользователь выиграл, frozen amount снимается, а на доступный баланс начисляется `potential_payout`.
9. Если пользователь проиграл, frozen amount окончательно списывается.
10. Бот присылает результат уведомлением, историю ставок можно посмотреть в меню («📋 История»).

Пример: баланс 1000, ставка 100 с odds `2.00`.

```text
до ставки:      balance=1000, frozen=0
после /bet 100: balance=900,  frozen=100
win:            balance=1100, frozen=0
loss:           balance=900,  frozen=0
```

`last_known_match_id` сохраняется именно при привязке аккаунта, чтобы старые матчи не были приняты за следующий матч после ставки.

## Запуск

Создайте локальный файл окружения:

```sh
cp .env.example .env
```

Заполните в `.env`:

```env
TELEGRAM_BOT_TOKEN=...
DOTA_PROVIDER=mock
```

Для локальной разработки по умолчанию используется `mock` provider. Он генерирует новый ranked match примерно раз в минуту.

Для сервера лучше использовать официальный Steam Web API, потому что OpenDota может быть недоступен из некоторых сетей:

```env
DOTA_PROVIDER=steam
STEAM_WEB_API_KEY=...
STEAM_BASE_URL=https://api.steampowered.com
DOTA_SYNC_INTERVAL_SECONDS=60
DOTA_MATCHES_REQUESTED=10
```

Steam Web API key можно получить на `https://steamcommunity.com/dev/apikey`.

Для fallback-режима можно включить `auto`: если задан `STEAM_WEB_API_KEY`, бот сначала попробует Steam Web API, затем OpenDota.

```env
DOTA_PROVIDER=auto
STEAM_WEB_API_KEY=...
OPENDOTA_BASE_URL=https://api.opendota.com/api
```

Для OpenDota напрямую:

```env
DOTA_PROVIDER=opendota
OPENDOTA_BASE_URL=https://api.opendota.com/api
DOTA_SYNC_INTERVAL_SECONDS=60
```

Запустите PostgreSQL, миграции, bot и worker:

```sh
make up
```

Логи:

```sh
make logs
```

PostgreSQL shell:

```sh
make psql
```

Остановка:

```sh
make down
```

## Меню бота

Всё управление — кнопками из главного меню (`/start`):

```text
🎮 Dota 2   🔫 CS2
💰 Баланс   💳 Пополнить
❓ Помощь    🏠 Меню
```

Это постоянная клавиатура внизу экрана (Reply Keyboard) — видна всегда, не пропадает при прокрутке чата, как нижнее меню в обычных приложениях. Внутри игрового раздела уже инлайн-кнопки под сообщением: привязка аккаунта (сообщением, без команд), 🎲 Сделать ставку (выбор суммы кнопкой или своим числом → тип ставки), 👁 Активная ставка, 📋 История, 🔁 Перепривязать. На каждом экране есть кнопка «🏠 В меню».

### Панель администратора

Администраторам (telegram_id из `ADMIN_TELEGRAM_IDS`) в постоянном меню дополнительно показывается кнопка «🔧 Админ» (обычные пользователи её не видят). Панель полностью кнопочная:

- коэффициенты ставок (Dota: победа/тотал/первая кровь, CS2: победа/тотал) и фильтры (мин. ММР, только соло-игры, привязка железа) — как раньше;
- «👥 Игроки» — постраничный список всех игроков с балансом и статусом, тап открывает карточку игрока;
- в карточке игрока: «➕ Начислить» / «➖ Списать» (бот просит прислать сумму числом) и «🚫 Заблокировать» / «✅ Разблокировать» — без единой команды;
- «🔍 Найти по ID» — быстрый переход к карточке игрока по его Telegram ID.

Старые команды `/admin`, `/admin_set_odds`, `/admin_adjust`, `/admin_block`, `/admin_unblock` и т.д. по-прежнему работают для совместимости, но не обязательны.

Старые команды оставлены для обратной совместимости (скриптов/автоматизации), но не обязательны для работы с ботом: `/link_dota <account_id>`, `/link_cs <steamid64|ник>`, `/balance`, `/bet <amount>`, `/active_bet`, `/cancel_bet`, `/history`, `/help`.

Пользователь должен включить публичную историю матчей в Dota 2: `Settings > Social > Expose Public Match Data`. Для CS2 нужен аккаунт на FACEIT (можно войти через Steam).

После следующего матча worker рассчитает ставку и бот отправит уведомление.

## Dota Provider

Провайдер выбирается через `DOTA_PROVIDER`:

- `mock` — локальная разработка без внешнего API;
- `steam` — официальный Steam Web API;
- `opendota` — OpenDota API;
- `auto` — Steam Web API, затем OpenDota как fallback.

Steam provider использует `GetMatchHistory` и `GetMatchDetails`, чтобы получить `match_id`, `start_time`, `lobby_type`, `game_mode`, `player_slot` и `radiant_win`. Worker логирует ошибки provider call и продолжает работу по другим пользователям.

## CS2 Provider (FACEIT)

У Valve нет публичного Steam Web API с историей матчей CS2 (в отличие от Dota). Поэтому реальные матчи CS2 отслеживаются через FACEIT Data API v4 — это единственный практичный бесплатный источник, привязанный к Steam-аккаунту игрока.

Провайдер выбирается через `CS_PROVIDER`:

- `mock` — локальная разработка без внешнего API, генерирует новый матч примерно раз в минуту;
- `faceit` — реальные матчи через FACEIT.

```env
CS_PROVIDER=faceit
FACEIT_API_KEY=...
FACEIT_BASE_URL=https://open.faceit.com/data/v4
CS_SYNC_INTERVAL_SECONDS=60
```

`FACEIT_API_KEY` — бесплатный server-side API key, получить можно на `https://developers.faceit.com` (создать приложение → API keys → Server-side key).

Привязка аккаунта принимает SteamID64, ссылку на профиль Steam или FACEIT-ник. Бот находит FACEIT-профиль игрока, а затем отслеживает завершённые матчи в CS2 через историю матчей FACEIT. Доступны два типа ставок: 🏆 победа в следующем матче и 💀 тотал килов в матче больше порога. Ставка на «первую кровь» есть только для Dota — FACEIT не отдаёт данные о первом килле без разбора демо-записи матча.

## Миграции

Миграции лежат в `migrations/`. При `make up` запускается one-shot compose service `migrate`.

Вручную:

```sh
make migrate-up
make migrate-down
```
